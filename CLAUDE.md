# Claude — instruções pra este repo

Este projeto usa a convenção agente-agnóstica **`AGENTS.md`** — um único
arquivo de instruções que serve pra qualquer agente (Codex, Cursor,
Manus, Grok, Gemini, Aider, Claude Code, etc.). Não duplicamos o
conteúdo aqui pra não sair de sincronia.

**➡️ Leia [`AGENTS.md`](AGENTS.md).**

Se você usa uma ferramenta que carrega instruções por outro caminho
convencional (`.github/copilot-instructions.md`, `.cursor/rules/`,
`.windsurfrules`, `.gemini/`), abra um arquivo lá com o mesmo pointer.
